Starting up and connecting

If you seeCheck
Server window: Failed to connect to Micro-Manager.Micro-Manager must be open before the server starts. Close the server window, open Micro-Manager, then start the server again.
Server window: Another server instance is already running on port 5000!A server window is already open. Use that one.
Connection Error: Cannot connect to microscope server.The server window is closed or still starting. Wait for Ready for connections..., then click Connect Now again.
Objective Pixel-Size Mismatch -- Workflow CancelledThe objective chosen in Micro-Manager differs from the one in QPSC, or Micro-Manager has the other camera's configuration loaded. See camera configuration files.
Camera ROI Mismatch -- Workflow CancelledThe camera image is cropped in Micro-Manager. Clear the ROI there.
The liquid crystals behave oddly or settings do not stickClose OpenPolScope and recOrder if either is open. Only one program should control the crystals.
Camera configuration files: Hamamatsu or Oryx

Each camera has its own Micro-Manager configuration and its own QPSC configuration file, and the two must describe the same camera. In QuPath, open Edit > Preferences, category QuPath SCope, and check Microscope Config File: config_LCPolScope_Hamamatsu.yml for the Hamamatsu or config_LCPolScope.yml for the Oryx. After a change, click Switch now in the Switch Microscope dialog. A calibration applied with one file does not reach the other. For the Oryx camera, use PORT position 2 (R80).

Swing, wavelength and scheme are shown for checking only, and should read 0.05 waves, 549 nm and 5-State. After Apply to acquisition, tick the black level box if it appears.

Camera settings

Retardance comes from brightness ratios between frames, so the camera must not adjust itself. The Ready to acquire? box in LC-PolScope Setup shows a Fix line for the camera when something is wrong.

  1. In Micro-Manager's Device Property Browser, set Gain Auto and Exposure Auto to Off, turn gamma off, and choose a 12-bit or 16-bit pixel format.
  2. In LC-PolScope Setup, click Recheck. The camera line should no longer start with Fix.

Restarting Micro-Manager can bring back the camera defaults, so check again after a restart.

Exposure

Bright structures can push the camera past its limit in some of the five frames. That lowers the measured retardance and bends the angle without any error message. For tissue sections, the saved exposure is right. For the test target or anything above about 10 nm, use a shorter exposure.

SampleExposureSaturates above about
Tissue sections, faint collagenAbout 140 ms (saved setting)10 nm
Test target, bright structures50 ms40 nm
  1. Type the exposure in the calibration dialog's Exposure (ms):, and again in Exposure, all states (ms): when you apply the calibration. Both the background and acquisition then use it.
Measuring whether your sample saturates
  1. In the Live Viewer, open the Camera tab and move to the brightest structure you will measure.
  2. Type the exposure in Exposure, all states (ms): and click Measure all states. A red row marked clipped means the exposure is too long.
  3. To keep a new exposure, click Save to Profile, then Save. It applies to every objective. Collect a new background afterward.

Background

If you seeCheck
Background profile neededChoose the profile for your slide type in Background profile:, or create one (below).
Check the background's swing states differ by ...The background was probably taken on tissue. Move to empty glass and collect again.
A faint negative copy of the sample in every tileSame cause: collect again on empty glass, out of focus.
Dark spots in the same place in every tileDust was in focus during the background. Defocus 10 to 20 um and collect again.
Creating a background profile

A background profile describes the setup on the stage: holder, slide type and mountant. Create one for each kind of slide.

  1. Open Extensions > QuPath SCope > Utilities > Image Quality > Background Profiles... and click New...
  2. Check the suggested values, type a Name:, and add the mountant after medium: under Attributes:.
  3. Leave Make this the active background profile ticked, confirm, and click Close.

Each objective needs its own background inside the profile.

Lines in the Ready to acquire? box

The box sits inside MODALITY-SPECIFIC OPTIONS in the acquisition dialog and never stops a run, so read it before you click Start Acquisition.
